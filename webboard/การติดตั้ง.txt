ขั้นตอนการติดตั้ง ::
- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - 
1. หลังจากดาวน์โหลดเว็บบอร์ดแบบ Text File มาแล้ว ให้แตกไฟล์ออกมา จะเห็นว่ามีไฟล์ .php อยู่ และมี โฟลเดอร์อยู่ 2 โฟลเดอร์คือ
    - mail2me => เก็บไฟล์ที่เป็นฟอร์มสำหรับส่งเมล์
    - pic => เก็บรูปภาพที่ใช้ในเว็บบอร์ดทั้งหมด

2. ปรับแต่งไฟล์ config.php ก่อนอัปโหลดขึ้น Server โดยมีคำอธิบายอยู่ในไฟล์แล้ว (ปรับแต่งตามที่อธิบายได้เลย)

3. สมมุติมีเว็บชื่อ http://comspu.thethai.net 
	ให้สร้าง directory ชื่อ webboard (หรืออื่นๆ ตามต้องการ แต่แนะนำชื่อนี้แหละดีที่สุด) โดยเวลาสร้างให้กำหนดโหมดเป็น 777 ด้วย (CHMOD 777)
	ถ้าสามารถเปลี่ยนโหมดได้นะ (แต่ที่ Thethai.net เปลี่ยนไม่ได้ ก็ไม่เป็นไรครับ) ก็จะได้เป็น http://comspu.thethai.net/webboard/

4. จากนั้น อัปโหลดไฟล์ .php ไปไว้ใน directory ชื่อ webboard ที่สร้างไว้ 

5. สร้าง directory ชื่อ mail2me, pic ใน directory ชื่อ webboard จะได้เป็น
	http://comspu.thethai.net/webboard/mail2me/
	http://comspu.thethai.net/webboard/pic/

6. จากนั้น อัปโหลดไฟล์ ไปเก็บไว้ใน directory ให้ถูกต้อง

7. ถ้าเคยใช้เว็บบอร์ดเวอร์ชั่นเก่า (เว็บบอร์ด Text File เวอร์ชั่น 2.0)  ต้องรันไฟล์ upgrade.php ก่อนใช้งานเว็บบอร์ดด้วย
	โดยไฟล์ upgrade.php จะทำการเพิ่มข้อมูลที่จำเป็นในไฟล์ "หัวข้อคำถาม" ให้

8. เมื่ออัปโหลดเสร็จก็สามารถใช้งานเว็บบอร์ดได้ทันที


หมายเหตุ :: 
ในเวอร์ชั่นก่อนๆ ต้องสร้าง Directory สำหรับเก็บข้อมูลคำถาม-คำตอบ แต่ในเวอร์ชั่นนี้ เพียงแค่กำหนดชื่อ Directory ในไฟล์ config.php
โปรแกรมจะสร้างให้อัตโนมัติ ซึ่งสามารถนำไปประยุกติ์ใช้ กับการแบ่งหมวดหมู่เว็บบอร์ดได้



วิธีการเรียกใช้เว็บบอร์ด ก็จะทำได้ดังนี้ ::

<a href="http://comspu.thethai.net/webboard/webboard.php">เว็บบอร์ด</a>
หรือ
<a href="../webboard/webboard.php">เว็บบอร์ด</a>

3. โปรแกรมเว็บบอร์ดแบบเก็บข้อมูลใน Text File เป็น Freeware ฉะนั้นห้ามทำการซื้อ-ขาย โดยเด็ดขาด

ถ้ามีปัญหาในการติดตั้งเว็บบอร์ด สามารถถามผ่านทางเว็บบอร์ดของเว็บพี่แสนได้
