ทำ WEBBOARD แบบ TXT คล้ายๆของ Thaimisc พัฒนาโดย พีกับยู

*วิธีการติดตั้ง*

1. ใช้โปรแกรม Notepad (อยู่ที่ Start -> All Programs -> Accessories -> Notepad) เปิด File ชื่อ config.php ครับ
2. ให้ไปแก้ไข CODE ในไฟล์นี้ครับ (ที่สำคัญจะอธิบายเป็นภาษาไทย)
3. แก้เสร็จแล้วก็ Save ครับ (ไปที่ File --> Save นะ)
4. เสร็จแล้วให้ UPLOAD ไฟล์ทั้งหมดขึ้นไปใน SERVER ที่คุณใช้เลยครับ
5. ใช้โปรแกรม FTP ของคุณทำการ เปลี่ยนโหมดไฟล์ - Folder (CHMOD) ของไฟล์ดังต่อไปนี้ (สำหรับ Unix/Linux) ครับ สำคัญมากครับ 

        ไฟล์ - Folder ที่ต้องเปลี่ยน		CHMOD เป็น
                   lastip.txt			       666
                number.txt			       666
	toc.txt			       666
           โฟลเดอร์ชื่อ question		       777
   โฟลเดอร์ชื่อ question/imagefiles		       777
                นอกเหนือจากนี้		                 ปล่อยไว้ไม่ต้องเปลี่ยน

6. ก็เป็นอันเสร็จสิ้นการติดตั้งครับ เปิดใช้งานได้เลย (หน้าหลักของ Webboard คือ webboard.php)
7. ใครมีข้อสงสัยอะไรก็อีเมล์มาถามกันได้นะครับที่ au_cty@hotmail.com ครับ
